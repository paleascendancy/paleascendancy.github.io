# Publicar a Pale Ascendancy no Vercel

## Opção recomendada
1. Entre no Vercel com GitHub.
2. Add New → Project.
3. Importe `paleascendancy.github.io`.
4. Para este site estático, mantenha os campos de build no padrão quando o Vercel não pedir configuração.
5. Clique em Deploy.
6. Depois, em cada atualização, faça commit/push no GitHub. Com a integração Git ativa, o Vercel cria uma nova implantação automaticamente.

## GitHub Pages
O GitHub Pages pode continuar ativo como endereço de backup enquanto o Vercel é usado como hospedagem principal.
